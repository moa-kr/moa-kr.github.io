# 모아 허브 (MOA Hub)

포켓몬카드모아와 회사복지모아를 소개하고 이동을 안내하는 루트 허브 페이지입니다.

- https://moa-kr.github.io/ — 허브 (이 저장소)
- https://moa-kr.github.io/pokemoa/ — 포켓몬카드모아
- https://bokjimoa.onrender.com/ — 회사복지모아

## 구성

- `index.html` — 허브 본문: 두 사이트 소개, 이용 안내, 자주 묻는 질문, 운영·문의
- `privacy.html` — 허브 개인정보처리방침 (허브 자체는 쿠키·광고 없음)
- `ads.txt` — Google AdSense `pub-2702295880931505` 승인 레코드
- `sitemap.xml`, `robots.txt` — 검색 로봇 안내

## 광고 정책

허브는 안내(내비게이션) 페이지이므로 **AdSense 스크립트와 광고 영역을 두지 않습니다.**
광고는 콘텐츠가 있는 각 사이트(포케모아·복지모아) 화면에서만 게재합니다.
(2026-11-20, 애드센스 “게시자 콘텐츠가 없는 화면에 광고” 지적 대응)

GitHub Pages(브랜치 `main` / 루트)로 서빙합니다.
